# Figures

Generated by [`scripts/make_figures.py`](../../scripts/make_figures.py):

```bash
python scripts/make_figures.py
```

Each figure is rendered twice — `*_light.png` and `*_dark.png` — so the README
can serve the variant that matches the reader's GitHub theme through a
`<picture>` element.

| File | Source data |
|---|---|
| `cohort_cutoff_*` | `data/processed/cutoff_criteria_summary.csv`, `cumulative_revenue_per_sessions.csv` |
| `k_selection_*` | `data/processed/user_features_labels.csv` (feature matrix re-scaled and re-projected) |

`user_features_labels.csv` is not versioned, so regenerating the middle two
requires rebuilding it first — see [`data/README.md`](../../data/README.md).

## Design notes

Colours come from a categorical palette validated for colour-vision deficiency:
slots blue `#2a78d6`, orange `#eb6834` and aqua `#1baf7a` in light mode, stepped
to `#3987e5` / `#d95926` / `#199e70` for the dark surface. Worst adjacent-pair
separation is ΔE 24.7 (light) and 26.8 (dark) under protanopia simulation, well
clear of the ΔE 8 floor.

Two rules shaped the charts:

- **One y-axis per panel.** Inertia and silhouette live on different scales, so
  they are two panels rather than one chart with twin axes.
- **Identity is never carried by colour alone.** The cluster figure is faceted
  one panel per segment with a titled heading, which also supplies the relief
  the light-mode aqua needs (2.74:1 against the light surface).

## On the cluster figure

The segments overlap heavily when projected to two dimensions — they were fitted
in fourteen — so plotting all three in one scatter produced an unreadable smear
with colliding labels. Small multiples show each segment against the rest in
grey instead. The silhouette of 0.15 is reported on the figure rather than
hidden: the separation is real but weak, which is the honest reading.
